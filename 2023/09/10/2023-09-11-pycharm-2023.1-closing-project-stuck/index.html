Post：2023-09-10 Tags：/ 那些年遇到的坑 / Visit：

问题描述

pycharm 切换项目/重启，一直卡在 closing project

原因分析

https://youtrack.jetbrains.com/issue/PY-59980/PyCharm-2023.1-issue-closing-project-window-stuck-PyPIPackageUtil.lambdaparsePyPIListFromWeb

解决方案

  1. 升级 pycharm 到 2023.3
  2. pycharm 主页 HELP -> Find Action -> 输入 Registry -> 禁用 ide.await.scope.completion
